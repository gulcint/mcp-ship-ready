Yalnızca `finding.file`/`skippedPaths`'e uygulanır — `ruleId`/`message`

**2. Toplam kaynak sınırı (`src/scanner/walk.ts`):**
`collectScannableFiles` generator'a çevrildi (`Generator<ScannedFile,
WalkSummary>`) — dosyalar tek tek `yield`'lanır, hepsi aynı anda
bellekte tutulmaz. Yeni `WalkLimits { maxFiles, maxTotalBytes }`

truncated`/`truncationReason`) `scan()`'a taşınır. `ScanReport`'a
`partial`/`partialReason`/`skippedPaths` eklendi; **`compliant =
findings.length === 0 && !partial`** — kısmi taramada sıfır bulgu asla
"uyumlu" diye raporlanmaz (Riskler'deki yanlış-negatif uyarısı).

**3. EACCES dayanıklılığı (`src/scanner/walk.ts`):** `readdirSync`/
`statSync`/`readFileSync` çağrıları tek tek try/catch'e alındı; hata
(EACCES dahil, genel) o yolu atlar ve `skippedPaths`'e ekler, taramayı
düşürmez. Kök dizinin kendisi okunamıyorsa da (`realpathSync`/ilk

Claude Code dokümanı, `code.claude.com/docs/en/slash-commands.md`

`` !`<command>` `` sözdizimi komutu Claude Code'un kendisi, skill
içeriği modele ulaşmadan ÖNCE çalıştırır — model bu çalıştırmayı
"yazmaz", dolayısıyla QA'in gördüğü sapma (önek/tırnak atlama) yapısal
olarak imkânsız hale gelir. Aynı dokümana göre enjekte edilen komutlar
yine `allowed-tools`'a karşı izin kontrolünden geçer (eşleşmezse komut
